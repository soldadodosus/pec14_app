FONTE DO ÍCONE PEC 14
=====================

A fonte oficial é ../assets/icons/app_icon.png. Use um PNG quadrado; 1024x1024 pixels ou maior é recomendado.

Para regenerar os ícones Android, iOS, Web, Windows e macOS, execute na raiz do projeto:

   flutter pub get
   dart run flutter_launcher_icons

Os recursos Linux são incluídos pelo CMake do runner durante o build Linux.
